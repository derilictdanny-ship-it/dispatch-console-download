# Dispatch Call Console: download

A calling console for truck dispatchers. It finds small carriers, tells you who to call first, shows your script and answers while you are on the phone, and keeps your call notes.

**You need a license key to use it.** Get one from The Model Logistics.

## Install (Windows)

1. Go to the **Releases** page on the right and download **DispatchConsole-Setup-UNSIGNED.exe**.
2. Run it. If Windows says **"Windows protected your PC"**, click **More info**, then **Run anyway**. (The installer is not code-signed, so Windows does not know the publisher.)
3. Open **Dispatch Call Console** from the Start menu or the desktop icon. It opens in your browser.
4. Paste your license key and press **Activate**. The first activation needs internet.
5. In **Settings**, add your own AI key (for example a free Gemini key) so live suggestions and notes work.

## Good to know

- Use **Chrome or Edge** on a computer.
- Calls are placed through your own **Google Voice**: the console opens the call screen and you press Call.
- Your leads, notes and keys stay on your computer. Updating or uninstalling does not delete them.
- To update, run the newer Setup file over the old one.
- Record or transcribe calls only where the law allows. Some states need everyone on the call to agree.

Windows only.
